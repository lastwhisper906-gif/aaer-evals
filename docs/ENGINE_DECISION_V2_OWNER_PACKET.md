> 사전 등록 경로로 인용하는 **"ENGINE_DECISION v2 (FPR-매칭 비교 + 대조군
> 확장)"** 는 현재 어떤 파일에도 존재하지 않는다. 본 패킷은 그 v2의
> **소유자 검토용 초안**이다 — BN-10 해소 조건("owner packet containing a
> v2 draft ... signed before Cycle-2 registration")의 루프 실행 가능
> 반쪽. **이 문서는 아무것도 결정하지 않는다**: 임계값·대조군 집합·규모
> 선정 전부 소유자 서명 사항이며, `specs/` 는 보호 경로라 v2의 정식 등재
> (`specs/ENGINE_DECISION.md` 개정)는 소유자의 손으로만 한다 (INV-18).
> 게이트: `docs/OWNER_QUEUE.md` **Q-F12**. 채택 시한 제약: **Cycle-2 등록

## 0. 왜 v2가 필요한가 (기록된 근거의 재서술 — 신규 주장 0)

- E2 조기성 결과에서 "LLM 리드타임 우위"처럼 보였던 것은 **임계 비대칭
  아티팩트**로 판명되었다 — LLM 플래그는 대조군 오탐 71.4%(5/7)를 동반한
  임계에서, B3 게이트는 오탐 0/7인 임계에서 읽혔다. 이것이
  DIRECTION_CONTEXT가 "FPR-매칭 비교가 비타협인 이유"로 기록한 사건이다.
- 결과를 본 뒤의 임계값 재보정(post-hoc recalibration)은 **범주적으로
  기각**되어 있다 — 유일한 통로는 사전 등록된 v2 경유의 전향(Cycle-2
  sealed) 검증이다.
- n=7 대조군에서는 오탐 0/7이어도 CP95 상한이 41.0%에 남는다 — 대조군
  확장 없이는 어떤 Cycle-2 전향 결과도 오탐(false-positive) 주장을
  지지할 수 없다 (BN-01이 BN-10을 경유하는 이유).

## 1. FPR-matched readout rules (FPR-매칭 판독 규칙) — v2 초안 §A

**초안 원칙 (소유자 확정 대상)**: Cycle-2 판독에서 LLM 대 결정론
베이스라인(B3/B4)의 어떤 비교 주장도 **동일(또는 매칭된) 대조군 오탐
수준에서 읽은 값**으로만 한다. 임계 그리드는 unseal 이전에 동결한다.

- **초안 규칙 스케치**:
  1. 비교 대상 각 채널(LLM·B3·B4)에 대해 **사전 등록 임계 그리드**를
     seal 이전 커밋으로 동결한다 (사후 그리드 추가 금지).
  2. 리드타임·탐지율 비교는 **대조군 플래그 수가 매칭되는 임계 쌍**
     에서만 성립한다 — 매칭 불가능하면 "비교 불성립"으로 기록하고 비교
     주장을 생략한다 (fail-closed, ENGINE_DECISION §4b 비교 성립 조건과
     동형).
  3. 모든 셀에 Clopper–Pearson 95% 구간 병기 (DECISION_TABLE 규약 유지).
     연속 곡선(ROC) 주장 금지 유지.
  4. 판독은 기계적 스크립트(`analysis/engine_verdict.py` 계열의 v2
     후속)가 수행하고, 규칙 밖 서사는 판정에 영향을 주지 못한다 (v1 §0
     원칙 승계).
- **옵션**: (A) 정확 매칭 — 대조군 플래그 수 동수인 임계 쌍만 비교 ·
  (B) 밴드 매칭 — 오탐률 차이가 사전 등록 밴드 이내인 쌍까지 허용 (밴드
  값은 소유자 서명 사항) · (C) 병기 판독 — 매칭 강제 없이 전 임계 오탐률
  동시 표기만 의무화 (가장 약함 — 비대칭 아티팩트 재발 여지).
- **근거**: §0 첫째 항목 — 비대칭 판독이 실제로 오독을 만든 실측 사례가
  이 저장소에 있다.
- **세션 기본 조치**: 없음 — 옵션 선택은 서명 사항.

## 2. Control-expansion selection protocol (대조군 확장 선정 프로토콜) — v2 초안 §B

**초안 원칙 (소유자 확정 대상)**: 확장 대조군은 기존 대조군과 동일
프로토콜(INV-04)·동일 PIT 규율(INV-01)로, **선정 규칙을 채점 이전에 커밋**
하고 사후 교체를 금지한다.

- **초안 프로토콜 스케치**:
  1. 선정 기준은 기존 대조군 매칭 규약(`analysis/HOLDOUT_CONTROLS_PLAN.md`
     계열)을 승계하고, 이탈이 필요하면 이탈 항목을 v2 본문에 사전 명시.
  2. 선정 결과(티커 목록)는 Cycle-2 seal 이전, 어떤 신규 채점 이전에
     단독 커밋 — freeze-commit-then-run.
  3. 신규 데이터 fetch가 필요하면 소유자 입회 감독 세션에서만 (INV-23).
- **규모 옵션 (예시 산술 — 오탐 0건일 때 CP95 상한, 결정론 계산)**:
  (A) **n≈20** — 0/20이면 상한 ~16.8% · (B) **n≈30** — 0/30이면 상한
  ~11.6% · (C) **n≈50** — 0/50이면 상한 ~7.1% · (D) 소유자 지정 기타
  규모. 참고 현황: n=7의 0/7은 상한 41.0%.
- **규모 선정 근거: OPEN** — DIRECTION_CONTEXT Q12가 기록하듯 "그 이상의
  규모 선정 근거"는 미기록 사유로 남아 있다. **본 패킷은 규모를 결정하지
  않는다** — 위 산술은 선택지의 통계적 결과를 보여주는 예시일 뿐이며,
  비용·조달 가능성·매칭 품질 대 구간 폭의 교환은 소유자 판단 사항이다.
- **세션 기본 조치**: 없음 — 규모·집합 결정 전부 서명 사항.

## 3. Post-E2 history disclosure (E2 이후 이력 공개) — v2 초안 §C, PROJECT.md §5-6

**초안 원칙**: v1 스펙(§5)은 "판정 개정은 E2 실행 전에만 — 실행 후 변경은
이력 공개 의무 (PROJECT.md §5-6)"를 등록했다. v2는 E2 산출물을 열람한
뒤에 작성되는 개정이므로, v2 본문에 다음 공개 절을 **의무 포함**한다:

- **공개 절 초안 문안**:
  1. v2 작성 이전에 열람된 것의 열거 — E2 판정 산출물, DECISION_TABLE
     (오탐 71.4% 비대칭 관찰 포함), buyer-metrics, [EXPLORATORY] 결합
     규칙 후보(사후 규칙임이 이미 표에 공개됨).
  2. 그에 따른 구속 범위 — **v2 규칙은 전향(Cycle-2 sealed 예측)에만
     적용**된다. v1/E2 동결 데이터를 v2 규칙으로 소급 판독한 값은 성능
     주장으로 인용 불가 (DECISION_TABLE §5 경고 문안과 동일 규율).
  3. v1 이력 보존 — `specs/ENGINE_DECISION.md`의 v1 판정 규칙·기존 개정
     (§4b, §3 주석)은 수정 없이 보존하고 v2는 추가 절로만 등재
     (INV-06 append-only 정신, E-001 병행 경로 선례).
- **옵션**: (A) 공개 절을 v2 스펙 본문에 내장 (단일 문서 완결) · (B)
  공개 절을 별도 문서로 두고 v2에서 링크 (스펙 간결, 사슬 분산 위험).
- **세션 기본 조치**: 없음.
