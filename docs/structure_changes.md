# Structure changes

One line per change to how the project is built or governed. Newest last. No
codes, no cross-references, no approval state.

2026-09-06 switched to forward prediction — seal and signature machinery removed, all names in plain language.
2026-09-06 old-design decision — superseded by the new direction.
2026-09-06 the earlier experiment moved to archive/ and frozen at tag archive-v1; its gates were green on Python 3.12 (966 passed) at that commit, and the new CI does not run them.
2026-09-06 the branch review-response/2026-09-04 — the head-to-head between the frozen formula baselines and the model, and the answer to the third external review — is preserved at tag archive-v1-review-response; it is not contained in archive-v1 and was not merged — needs judgment.
2026-09-06 review-response branch diverges from the archived tip; preserved as a tag; merging the two published-results histories needs judgment — not blocking.
2026-09-06 that tag is archive-review-response; the earlier archive-v1-review-response points at the same commit and is left in place rather than deleted, because a line above already names it.
2026-09-06 main requires the CI check and nothing else — no reviewer, auto-merge on, branch deleted on merge; a pull request waiting for a click was itself the bottleneck the rules forbid.
2026-09-06 the pinned interpreter is Python 3.12 and entry points refuse to run on anything else, not only CI.
2026-09-07 the duplicate tag archive-v1-review-response is deleted; archive-review-response is the one that survives, on the same commit — the line above naming the deleted one is history, not a live pointer.
2026-09-07 the directory pages moved to docs/runs.md and docs/rules.md, and the README exception in the append check is gone; everything under runs/ · rules/ · events/ is a record whatever it is called.
2026-09-08 the predict stage becomes three layers — two readers see filings, two comparers see reader reports and the market table, two supervisors see reports only — and a per-run, per-agent input directory is the isolation boundary, asserted by a test, because worktrees isolate execution and not data.
2026-09-08 the notes-numbers reader is merged into the numbers reader for version one; findings taken from tables inside the notes go under their own heading so the later split does not have to re-derive which was which.
2026-09-08 EDGAR companyfacts becomes the source for the trend table and the independent expected value for every trend fixture, because the current fixtures' trend values came from the code under test; Q4 is derived as annual minus nine-month year-to-date, cross-company comparison uses calendar frames, and a period whose value changes between filings is a quiet-restatement trace.
2026-09-08 a market table enters the pipeline — abnormal return against a broad-market series and a sector ETF, two reaction windows recorded separately, short interest attached by publication date and never by settlement date — and only the comparers may read it.
2026-09-08 the cutoff is extended for market data alone: an agent may see through the filing date plus two trading days, and the 60-trading-day outcome window starts on the third trading day and is visible only to the scorer.
2026-09-08 the direction of the 60-trading-day abnormal return is added as a target under both questions, scored by Brier and hit rate, with the count of insufficient answers reported beside it; two caveats travel with that row in the scorecard template — post-2006 drift is near zero outside small capitalizations, and published anomalies lose roughly half their margin after publication.
2026-09-08 formula baselines and two controls are scored in the same scorecard and never merged into the pipeline's number; the Beneish M-score is the first row of the accounting scorecard, so if the layers do not beat it the scorecard says the structure adds nothing.
2026-09-08 the single-agent control uses the same model as the supervisor, and the shuffled-report control feeds a supervisor one company's numbers report with another company's notes report; a matching score means the supervisor is not reconciling.
2026-09-08 seven accounting-reliability indicators and one financial-pressure indicator are added while the two-by-two thresholds stay where they were, which loosens both tiers on purpose — moving a threshold inside the change that adds the indicators it counts would hide it.
2026-09-08 the custom harness is replaced by Claude Code's own loop; kept are the append check, the refute protocol that an expected value comes from the source, and the seeded-defect canary as a monthly scheduled task; dropped are the work ledger and its six states, the cycle audit, the write-restriction guard and its self-test, the doc-bloat penalty, the stop file, the builder and reviewer session pair, and the background launcher.
2026-09-08 preflight found no settings file in the repository, so no harness hook had to be removed, and the plain-name check exists only inside the harness — writing it into this repository is the first task-list item, and its hook is written now and fails open until it lands.
2026-09-08 the EDGAR companyfacts probe returned 503 standard tags for one company, every observation carrying the accession and filing date that reported it, 46 periods reported more than once, and calendar frames present — the trend table, the restatement trace and the shares-outstanding denominator all rest on that one request.
2026-09-08 the price source is still unchosen: Stooq answered a plain read-only request with a JavaScript proof-of-work page under both a plain and a browser user agent, and the Yahoo chart endpoint refused unauthenticated requests, so neither candidate reached the delisted-ticker question — the market module is built and tested against a frozen price fixture, and the source is decided before the universe is frozen, not before.
2026-09-08 expansion is designed and not started: the universe is drawn from the EDGAR full index as of a past date rather than today's ticker list, delisted companies stay in, small and mid capitalizations are included on purpose, and the cross-section is cut by calendar frames.
