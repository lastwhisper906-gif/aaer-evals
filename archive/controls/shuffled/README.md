# The shuffled-report control, retired

> 짝지어진 회사 panw 같은 경우에는 굳이 후보들을 짝 지을 필요 없다고 생각한다
>
> English: no company pairing.

The owner's decision of 2026-09-23, quoted verbatim above. The shuffled-report control asked whether the supervisor actually reconciles the numbers side of a filing with its notes side, or pattern-matches one of them: it handed the supervisor one company's `report_numbers.md` and `report_numbers_vs_market.md` together with another company's `report_notes_text.md` and `report_notes_vs_market.md`, the partner being the next of the twelve by ticker, and scored the answer as the `shuffled_accounting` and `shuffled_pressure` rows beside the pipeline's. It is retired by that decision, which is about the pairing itself: no company is paired with another. What the pairing had cost was already on record in `docs/needs_judgment.md`: seven of the twelve fixed pairings put the partner's annual report after the filing being scored, so the cutoff refused them, and three open questions were about the crossing alone. The question it asked still stands, and the control that would ask it with no second company, running the same supervisor on one filing with only one side's reports, is an open row in `docs/needs_judgment.md`, not built. What is kept here is the tree as it stood on `main` when it was retired, not run and not maintained: `src/control_shuffled.py`, its test `tests/test_control_shuffled.py`, and the hand-written report pair `tests/fixtures/shuffled_report_pair/` the test crossed. The test's imports name the live tree's paths, so it cannot run from here; `pytest.ini` does not collect `archive/` in any case. The tests in it that judged `src/prediction_schema.py` rather than the crossing moved to `tests/test_prediction_schema.py`.
